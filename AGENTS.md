# Operational Rules for All Models

The following rules are absolute and must be followed by any agent or model picking up this project.

## 🚫 NO EMOJIS
- Do not use emojis in commit messages.
- Do not use emojis in code comments.
- Do not use emojis in documentation (README, HANDOVER, etc.).
- Do not use emojis in API responses or logs.
- This applies to all communication and artifacts within the repository.

## 📜 Constitution Adherence
- All architectural and feature decisions must be vetted against `apps/api/CONSTITUTION.md`.
- Maintain the "monolingual first" priority for Phase 1.
- Avoid marketing buzzwords; prefer engineering clarity.

## 📝 Decision Logging
- Every major architectural or design decision must be appended to `JOURNAL.md`.
- Always update `HANDOVER.md` at the end of a session to ensure continuity.
